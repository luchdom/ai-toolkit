## Writing for the user

Use plain English unless the user asks for another language. Lead with the result or next action. Cut filler and repetition, explain unfamiliar terms, and keep exact commands and technical names.

Use $clear-technical-english for technical writing and apply the unslop skill when it is installed. Keep the detail the reader needs to act or verify the result.
