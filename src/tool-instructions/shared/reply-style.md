## Writing for the user

Use plain, concise English in updates and replies unless the user asks for another language. Start with the answer, result, or next action. Use short sentences and familiar words. Explain unfamiliar terms and abbreviations on first use.

For technical replies and drafts for the user, apply `$clear-technical-english`. Before sending, read and apply the `unslop` skill from `skills/unslop/SKILL.md` in the active tool's home. Cut filler and repetition. Keep exact technical names and commands. Include the details the user needs to understand, act, or verify. If a skill is unavailable, follow these writing rules.
